第1章 HTMLの基本構造とメタデータの解説

Webページの骨組みを作るための必須タグと、ブラウザや検索エンジンに裏設定を伝えるメタ属性のまとめです。

基本構造・メタ属性タグ一覧
タグ・属性名 役割と重要な仕様・記述ルール
<!DOCTYPE html> ドキュメントタイプ宣言。このファイルが最新の「HTML5」で書かれていることをブラウザに宣言する。
<html lang="ja"> すべてのHTML要素の親となるルートタグ。lang="ja"でページの主言語が「日本語」だと指定する。
<head> 画面には表示されない、文字コードやタイトル、検索キーワードなどの「ページの付加情報」を記述する場所。
<meta charset="UTF-8"> ファイルの文字コードを指定する。「最初の1,024バイト以内に記述しなければならない」という厳格なルールがある。
<meta name="author"> ページの制作者（作成者）の名前を指定する属性。
<meta name="keywords"> ページ内容を表すキーワードを3〜5つ程度指定し、ブラウザにサイトのテーマを伝える。
<meta name="description"> ページ全体の要約文（説明文）を記述する。検索エンジンの検索結果一覧の解説文として使われる。
<title> ページのタイトル。ブラウザの「タブ名」や、お気に入りに登録したときの名前として使われる。
<body> 実際にブラウザの画面上に表示される、すべてのコンテンツ（文章や画像など）を記述する場所。
<header> サイト共通のヘッダー情報（サイトタイトルやナビゲーションリンクなど）を囲む箱。
<nav> 他のページへのリンクや、ページ内リンク（メニュー）をまとめたもの。
<main> ページ内のメインコンテンツ（主要な中身）を囲むためのタグ。1ページに1つだけ配置する。
<section> 文書の「章」や「節」などの意味のある大きなまとまり（グループ）を作る。
<p> パラグラフ（段落）。一般的な文章を記述するときに最もよく使う。

第2章 表・箇条書き・メディア埋め込みの高度な解説

画像ファイル形式の特徴や、動画の複数形式（フォールバック）に関する詳細情報です。

第1節 画像ファイル形式（フォーマット）の特徴比較

各種形式のメリット・デメリットを整理した用語集です。

png（ピング、ピン）
透明処理（背景透過）が使えるのが最大の特徴。可逆圧縮方式なので、画質を変更しても元に戻すことができるが、jpgと比べるとファイルサイズが大きくなる。
jpeg（ジェイペグ）
一般的に最も使われている画像方式。圧縮率に優れる。非可逆圧縮タイプなので、一度画質を変更して保存すると元の画質には戻せない。色数の多い写真などに最適。
gif（ジフ、ギフ）
最大で256色まで扱える。ぱらぱら漫画のようなアニメーション表現ができるのが最大の特徴。
webp（ウェッピー）
Googleが開発した最新の画像形式。高画質な状態を保ったまま、jpgやpngよりもさらにファイルサイズを小さく軽量化できる。

第3節 動画のマルチ形式埋め込み（フォールバック構造）

ブラウザの環境（種類）に合わせて自動で再生可能なファイル形式を上から順に選択させる、sourceタグです。どの形式にも対応していない古いブラウザ向けに、内側に注意文（pタグ）を挟むルールになっています。

第3章 Macのパソコン効率化ショートカットキー：基本操作編

大学でのレポート作成や普段のネットサーフィン、固定概念にとらわれずすべてのPC作業が劇的に速くなる、基本中の基本キーの一覧です。

基本ショートカット一覧
キー操作 機能・役割の詳細な説明
Command + C 選択した文字やファイル、画像を一時的にパソコンに「コピー（複製）」する。
Command + V コピーまたは切り取った内容を、カーソルがある位置に「貼り付け（ペースト）」する。
Command + X 選択した文字をその場から消去（カット）しつつ、貼り付け用に記憶する。
Command + Z 操作を間違えたときや、文字を消しすぎたときに「1つ前の状態に戻す（取り消し）」。
Command + Shift + Z Command+Zで戻しすぎた操作を「もう一度やり直す（進める）」。
Command + A 開いているページやファイル内の文字・データを「すべて選択」する。
Command + S 現在編集中のファイルを「上書き保存（セーブ）」する。VS Codeではデータ消失を防ぐため必須の癖。
Command + F ページ内やファイル内から、特定の文字を探し出す「検索バー」を画面上に起動する。

第4章 Macのパソコン効率化ショートカットキー：アプリ・VS Code編

ブラウザのタブ管理や画面キャプチャ、そしてVS Codeでのプログラミング速度をハッカーのように高める応用キーです。

第1節 ブラウザ・ウィンドウ管理リスト

  • ブラウザのタブ操作
    • Command + T ： 新しいタブを瞬時に開く
    • Command + W ： 今見ているタブ（またはウィンドウ）を即座に閉じる
    • Command + Shift + T ： 間違えて閉じてしまったタブを履歴から大復活させる
  • アプリケーションの管理
    • Command + Q ： 今使っているアプリ（VS Codeなど）そのものを完全に終了する
    • Command + Tab ： マウスを使わずに、起動中のアプリを一瞬で切り替える

第2節 画面の撮影（スクリーンショット）の分類

レポート作成の証拠画面や、提出用の画面を撮影するためのMacの標準機能です。

Command + Shift + 3
画面「全体」をそのまま撮影して、デスクトップに画像として保存する。
Command + Shift + 4
マウスカーソルが十字になり、自分で「ドラッグして囲んだ部分だけ」を部分的に狙って撮影する。

第3節 VS Code（エディタ）専用の爆速コマンド

マウスで行を選択したりコピーしたりする手間を省き、キーボードだけでコードを書き換えたり、乱れた配置を一瞬で整えるためのテクニックです。

  1. Option + Shift + F ： インデント（字下げ）やコードのズレを綺麗に自動で整列（フォーマット）する。
  2. Command + / ： 選択した行を一発で「コメントアウト（一時的なプログラムの無効化・メモ化）」にする。
  3. Option + ↑ / ↓ ： 文字を選択せず、今カーソルがある行を「丸ごと上下に移動」させる。
  4. Shift + Option + ↑ / ↓ ： 今カーソルがある行を、その上下に「そっくりそのまま複製（コピー）」する。
  5. Command + X （文字選択なし） ： カーソルがある「行を丸ごと1行カット（削除）」する。
